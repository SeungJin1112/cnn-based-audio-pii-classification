# 0004 — splits.py (template-disjoint + length/label-stratified)

## 무엇을 했나
- `src/cnn/splits.py`:
  - `split_manifest()` — template_id 그룹 단위로 train/val/test 분할. 길이순 정렬 후 비례 충원(cur/target 최소)으로 배정 → template-disjoint + label-stratified + length 분산 동시 달성.
  - `build_original_eval()` — controlled-train 파일을 Original 평가셋에서 제외(누수 방지).

## 왜
- plan.md §8: stratified random만으로는 템플릿 암기·길이 confound를 막지 못함. speaker-disjoint는 화자 2~3명이라 미적용(통제 불가 confound로 명시).

## 결과 / 수치
- split: train 67.2% / val 16.3% / test 16.6%.
- **template-disjoint: split 간 공유 0개**.
- label-stratified: label0/1 모두 ~66–68/16/16–17%.
- length 분산: 평균 train 4.98 / val 4.82 / test 4.99 (1차 절대-부족분 방식의 4.65 vs 5.73 격차를 비례 충원으로 해소).
- Original 누수 제외: 2000 → 1502 (controlled-train과 겹친 498개 제외).
